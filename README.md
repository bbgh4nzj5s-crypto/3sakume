# Pricoletta 着せ替え操作確認用HTML試作

`index.html` をブラウザーで開いてください。`style.css` と `app.js` は同じフォルダに置いてください。

これは本番のPricolettaとは独立したダミーデータ専用の試作です。QRは実際には表示・生成しません。BOOK作品はメモリ上だけに保存され、再読み込みで消えます。PNGの書き出しも行いません。

操作可能：衣装交換、左右切替、ペア、位置・サイズ・角度・反転・レイヤー順、50操作履歴、検索、絞込み、コレクション選択、カテゴリ切替、背景、コーデ展開、BOOK仮保存・再編集・比較選択。

制限：衣装画像は絵文字の仮表示。指追従のカテゴリ横スワイプアニメーション、レイヤーの長押しドラッグ、QR本表示、PNG生成、永続保存、完全な検索・タグ仕様、iPhone実機検証は今後の確認対象です。
